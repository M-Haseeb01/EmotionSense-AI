# EmotionSense AI

EmotionSense AI is a Natural Language Processing (NLP) application that analyzes user text and predicts the underlying emotion using a pretrained Transformer model from Hugging Face.

---

## Working Flow

```
User Input
      │
      ▼
Text Preprocessing
      │
      ▼
Transformer NLP Model
      │
      ▼
Tokenization
      │
      ▼
Emotion Prediction
      │
      ▼
Display Emotion & Confidence Score
```

---

## Technologies Used

- Python
- Flask
- HTML & CSS
- Hugging Face Transformers
- PyTorch

---

## Installation

```bash
git clone https://github.com/M-Haseeb01/EmotionSense-AI.git

cd EmotionSense-AI

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt
```

---

## Run the Project

```bash
python app.py
```

Open in your browser:

```
http://127.0.0.1:5000
```
